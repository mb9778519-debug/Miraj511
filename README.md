# MIRAJ 511 CLIENT - Android Studio Project

Native Zero-Freeze Multi-Touch Keyboard Daemon & PvP HUD for Minecraft Bedrock Edition (`com.mojang.minecraftpe`).

## Quick Setup Guide:
1. Open Android Studio -> **Open...** -> select this project folder.
2. Let Gradle sync dependencies.
3. Connect your Android device or start an emulator with Android 8.0+ (API 26+).
4. Click **Run** ('app').
5. On your phone:
   - Grant **Overlay Permission** (`Settings.ACTION_MANAGE_OVERLAY_PERMISSION`).
   - Enable **MIRAJ 511 Hardware Daemon** in `Settings > System > Languages & Input > On-screen keyboard`.
   - Tap **Toggle HUD Overlay** switch.
   - Tap **Launch Minecraft Bedrock**!
6. In-game:
   - Tap the floating **511** badge to toggle Edit Mode (drag buttons anywhere).
   - Press **W** for W-Tap, **CTRL** for Sprint, **F5** to change camera, and **Q** to drop items!
